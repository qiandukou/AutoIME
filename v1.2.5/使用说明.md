# AutoIME — 输入法自动开关（Adobe / Autodesk 创意软件）

> **适用版本：v1.2.5（2026-11-13）**
> 本文件是「软件说明」，每个新版本都必须同步更新（新功能、新配置项、新限制）。

## 快速开始

1. 双击 `AutoIME.exe`（右下角托盘出现一个「英」字样小圆图标即已运行）
2. 打开 Photoshop / 3ds Max / Maya，正常用就行
3. 想退出：右键托盘图标 → 退出
4. 关于/反馈：右键托盘图标 →「反馈 / 联系作者」（或「关于 AutoIME」窗口内点反馈按钮），设置界面底部也有「反馈」按钮；点开后显示 QQ 邮箱与 QQ 号，可一键复制。本软件纯免费交流分享。

**建议**：右键托盘图标 → 勾选「开机自动启动」，以后不用管它。
> 如果提示写不进去（安全软件拦截），双击程序目录里的 `启用开机自启.cmd` 一次即可。

## 一句话

在这些软件里**要用快捷键时自动关闭输入法，鼠标点到输入框时自动打开输入法**——不切换输入法，你用的还是同一个搜狗/微软拼音。

---

## 原理（和「我的世界」IMBlocker 插件一样）

你原来遇到的问题是：中文输入法一开着，PS/Max/Maya 里按 `V`、`M`、`W` 这些字母快捷键就被输入法当成拼音吃掉了。

本程序**不切换输入法、也不碰键盘布局**，它只做一件事：**把输入法锁死或放行**。

```
鼠标在输入框里 / 正在打字  ->  放行：输入法「开」 -> 能打中文
其它所有时候（用快捷键）   ->  锁定：输入法「关」 -> 按键直接送到软件
```

三条硬保证：

1. **绝不切换键盘布局**（`AllowLayoutSwitch=0`）：语言栏不会跳、搜狗不会重载、你的键盘布局始终是原来那个
2. **严格锁定**（`StrictLock=1`）：不在输入框时，就算你自己按 `Shift` 把输入法撬开，程序也会在几十毫秒内关回去
3. **只在输入框里放行**：一旦光标进入输入框，立刻开中文，离开就锁上

> IMBlocker 是在游戏进程内部调用 `ImmAssociateContext(hwnd, NULL)` 把输入法从窗口上摘掉；
> 外部程序做不到这一步，等价手段是给目标程序的输入法窗口发 `WM_IME_CONTROL` + `IMC_SETOPENSTATUS`，
> 效果一样：输入法不参与按键处理。


## 三个软件里的具体表现

### Photoshop
* **画布上打中文**：⚠️ 需要教一次，见下面「PS 画布打字」一节
* **双击图层名改名字**：出现 I 型光标 → 自动开输入法
* **各种对话框里的输入框**（新建文档的尺寸、存储为的文件名）→ 自动开输入法
* **移动/画笔/选区等工具**：普通光标 → 输入法保持关闭，`V` `M` `B` `L` 等快捷键正常
* **不透明度、字号等数字框**：可以直接上下拖动数值，不用管输入法

#### PS 画布打字（v1.0.4 起自动，不用教）

PS 的画布文字光标是自绘的，认不出形状；而**它一进入画布文字编辑，整个脚本接口就会被锁住**
（`CurrentTool` 返回"应用程序忙"）。这个"忙"就是最可靠的信号——它只在真正编辑文字时出现。

于是 v1.0.4 的判断变成：

| PS 的状态 | 判定 |
|---|---|
| 脚本接口"忙" **且**上一次用的是文字工具（= 正在画布上编辑文字） | **输入框** → 开中文 |
| 当前工具是文字工具（`typeCreateOrEditTool`） | **输入框** → 开中文 |
| 脚本接口"忙"但上一次是画笔（= 正在涂抹，v1.0.6 修正） | 锁英文 |
| 画笔 / 移动 / 选区… | 锁英文 |

> 为什么要有"上一次用的工具"这个条件：PS 在**画笔涂抹**时也会把脚本接口锁住（同样报"忙"）。
> 只看"忙"会把画画误判成打字，所以必须结合"上一个已知工具"来判断。

读这个状态的方式：程序启动一个 `cscript` 助手（系统自带、受信任），
让它把 PS 当前状态写进 `AutoIME.pstool.tmp`，程序只读文件，不碰 COM。
助手每 1.5 秒刷新一次文件（v1.0.5 起），所以**长时间连续打字也不会掉回英文**。
在输入框里你按 `Shift` 自己切中/英时，程序会尊重你的选择，直到你离开这个输入框（v1.0.7）。

**怎么确认它在工作**：双击托盘图标 → 「PS 画布上的文字工具」组 → 右边那行

```
识别状态：文字编辑中(忙)        ← 正常（你正在画布上打字时）
识别状态：忙·上次是 paintbrushTool ← 正常（你正在涂抹，不会开中文）
识别状态：typeCreateOrEditTool  ← 正常（刚选了文字工具）
识别状态：paintbrushTool         ← 正常（画笔）
识别状态：读不到（双击启动PS工具助手.cmd）   ← 见下面
```

**如果显示"读不到"**（程序自己启动助手被安全软件挡住，或者没有 cscript）：

1. 到 AutoIME 所在文件夹，双击 **`启动PS工具助手.cmd`**
2. 它会开一个黑窗口跑一两秒就消失，助手已经在后台了（关窗口不影响）
3. 回到 PS 点一下画布试试；设置界面那行应该开始显示工具名
4. 重启电脑后再双击一次即可（也可以把这个 cmd 的快捷方式放进「启动」文件夹）

**再退一步**（连助手都跑不了的极端情况）：教一次光标 —— 选中文字工具 → 鼠标移到画布出现 I 型光标 → 按 `Ctrl+Alt+Shift+L`。
注意：v1.0.8 起"光标形状"判据默认关闭（PS 已由工具识别覆盖），教过的光标仍会生效。
### 3ds Max
* **命令面板里的输入框**（`CustEdit` 类）→ 自动开输入法
* **数值微调框 / 旋转器**（`SpinnerControl` 类）→ **强制英文**，这样输入数字时不会被拼音抢走数字键
* **MAXScript 监听器 / 编辑器**（`Scintilla` 类）→ 自动开输入法
* 视口里操作、按 `Q` `W` `E` `R`、`Alt+Q` 等 → 输入法关闭，快捷键正常

### Maya
* **Maya 是 Qt 界面**，所有文本框（属性编辑器、通道盒、渲染设置、脚本编辑器）鼠标移上去都是标准 I 型光标 → 自动开输入法
* 视口里操作、按 `W` `E` `R`、`Q` 等 → 输入法关闭

## 如果某个地方没有自动切换

程序靠"鼠标在不在输入框里"来判断，个别自绘界面可能认不出来。**教它一次**就好：

1. 把鼠标放到那个能打字的地方（比如 PS 图层面板里双击后的名字栏、文字工具的输入位置）
2. 按 `Ctrl + Alt + Shift + L`
3. 右下角浮标提示「已学习 Photoshop」→ 以后这个光标就认得出来了

学习结果存在 `AutoIME.learned.txt`，可以随时在诊断面板里清除。

### 诊断面板（`Ctrl + Alt + Shift + D`）

面板里实时显示：

```
前台程序 : Photoshop.exe  pid=1234  class=Photoshop
是否目标 : 是      自动控制: 开      方式: ime
-- 输入法 --
IME 窗口 : 0x311A54
输入法   : 当前是输入法(可切中文)   开/关=开   中英模式=0x401
-- 输入框判定 --
焦点控件 : CustEdit    插入符: 有
鼠标光标 : 可见  [形状像I型] [在本程序上]
光标哈希 : 8F3A...  ★已学习
判定     : >>> 输入框 —— 打开输入法(中文)
依据     : I型光标(形状)
```

判定不对的时候看**「依据」**这一行，就知道是哪个判据出了问题（可以在配置里单独关掉它）。

面板上还有三个按钮：**学习当前光标**、**试关输入法 3 秒**、**试开输入法**，方便你确认效果。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + Shift + I` | 手动开/关输入法（不影响自动判断） |
| `Ctrl + Alt + Shift + L` | 把当前鼠标光标学习为"文字光标" |
| `Ctrl + Alt + Shift + D` | 打开诊断面板 |
| `Ctrl + Alt + Shift + S` | 打开设置主界面（v1.0.9 新增） |

**这些键都能改**：打开设置界面 →「快捷键」分组 → **点进你想改的那个输入框，直接按新的组合键**，
它会自动记录（例如按 `Ctrl+Alt+Q` 就填 `CTRL+ALT+Q`），然后点「保存并应用」立即生效。

- 必须带 `CTRL` 或 `ALT`（只加 `SHIFT` 会抢正常打字，程序会拒绝）
- **打开设置界面时，程序会临时让出所有全局热键**（否则你想录的组合会被自己先吃掉，输入框收不到）；
  关掉设置界面自动恢复
- 如果某个组合被别的软件占用，保存时会弹窗明确告诉你哪几个没注册成功，换一个即可
- **注册失败会自动重试**（v1.1.6）：每 1.5 秒重试一次，占用解除后快捷键自动恢复，日志会写「热键恢复」

## 配置（`AutoIME.ini`，改完右键托盘 →「重新载入 AutoIME.ini」）

最常改的几个：

| 项 | 默认 | 说明 |
|---|---|---|
| `Enabled` | 1 | 总开关 |
| `Method` | ime | `ime`=只开关输入法（推荐）；`layout`=换成切换到英文键盘布局的旧方案 |
| `LeaveDelayMs` | 350 | 鼠标离开输入框后多久关输入法。觉得"关得太快/太慢"就调这个 |
| `EnterDelayMs` | 30 | 判断为输入框后多久开输入法 |
| `ManualOverrideMs` | 4000 | 你手动切了中/英后，程序暂停自动控制多久（仅在输入框里生效） |
| `StrictLock` | 1 | 1=严格锁定：不在输入框时强制关闭输入法，Shift 撬开也会立刻关回去 |
| `AllowLayoutSwitch` | 0 | 0=绝不切换键盘布局（只开关输入法），1=允许切到英文键盘 |
| `BadgeAlways` | 0 | 1=浮标常驻 |
| `AllApps` | 0 | 1=所有程序都生效 |
| `IBeamShape` | 0 | 是否用"光标形状像 I 型"来判定。PS 已由 PSToolRule 工具识别覆盖，此判据默认关闭；误判多保持 0 |
| `IBeamShapeLoose` | 0 | 放宽形状判定（允许更大的自绘 I 型光标），误判多就保持 0 |
| `PSToolRule` | 1 | 是否用 cscript 读 PS 当前状态来自动识别文字编辑。设为 0 则只用光标判据 |
| `CaretWindow` | 1 | 是否用"有文字插入符"来判定 |
| `TextClasses` | Edit,RICHEDIT,… | 认作输入框的窗口类名，逗号分隔 |
| `NumClasses` | SpinnerControl,… | 认作数字框、强制英文的窗口类名 |

`[Apps]` 段决定对哪些程序生效，`进程名=1`，默认已包含 Photoshop / 3dsmax / maya 各版本，并在 v1.2.0 起纳入主流 Adobe、Autodesk 软件（见下节清单）。

## v1.2.4 修复：托盘隐藏后可唤起设置 / 浮标常驻 / 配置兜底 / 浮窗拖动锁定 / 不透明度

**修了什么**：

1. **托盘隐藏后仍能打开设置（单实例双保险）**：单实例判定改为「同名进程检测 + 命名互斥锁」双保险，避免第二次双击又起一个相同进程；命中任一即通过内部事件唤起已运行实例的设置界面后退出，不再只弹「已在运行」；托盘图标被隐藏也能进设置。全局设置热键、`--settings` 命令行仍可用。
2. **浮标常驻生效**：勾选「浮标常驻显示」后浮窗持续显示，不被未知状态或离开打断而计时隐藏；非常驻行为不变。
3. **配置保存兜底**：退出前把当前配置写入 ini；各开关/勾选本就即时保存，本次补齐退出落盘。
4. **浮窗拖动/缩放修复 + 锁定开关**：去掉浮窗鼠标穿透样式，原先点击会落到下层窗口导致选不中、拖不动；新增「锁定浮窗位置/大小」，锁定后禁止拖动与右下角缩放。入口：设置界面勾选框、右键托盘菜单「锁定浮窗」。
5. **浮窗本体锁图标 + 右下角手柄缩放**：右上角锁图标随浮窗高度等比缩放——橙色闭合=已锁定，灰色开口=未锁定，点击直接切换；按住右下角手柄斜向拖拽调整大小（悬停斜向调整光标），字体、文字、锁图标随大小等比重排，文字单行省略不换行。
6. **浮窗选项保存即生效 + 不透明度滑块**：关闭「显示浮标」、切换「常驻」保存后浮窗立即显隐，不用重启；新增「浮窗不透明度」滑块（30%~100%），保存后浮窗透明度即时变化。

**怎么验证**：隐藏托盘图标后双击 exe，旧实例设置窗弹出；勾选常驻浮标后浮窗持续可见；改完设置退出重启后仍然保留；解锁状态下可拖动、缩放浮窗，锁定后按下不响应；点浮窗右上角锁图标切换锁定；滑块调不透明度保存后即时生效；按住右下角手柄拖拽缩放，字体与锁随尺寸重排，无残影。

**限制**：第二实例唤起依赖命名事件；若系统拦截命名事件（罕见），仍可走全局设置热键打开设置。

## v1.2.3 新增：状态浮窗常驻可选 / 可拖动缩放 / 可置顶

**改了什么**：

- **常驻可选**：设置界面「浮标常驻显示」（配置 `BadgeAlways`）控制浮窗是否一直存在；未常驻时按 `BadgeMs` 时长自动隐藏（沿用旧逻辑）。
- **可拖动**：按住浮窗主体（除右下角缩放手柄）拖到目标位置，松开后位置自动保存（`BadgeX` / `BadgeY`）。
- **可缩放**：拖动右下角手柄调整大小（最小 96×40，最大 600×300），松开后尺寸自动保存（`BadgeW` / `BadgeH`）；大字与两行小字随窗口比例自适应。
- **可置顶**：设置界面「浮窗置顶」与右键菜单「浮窗置顶」勾选框（配置 `BadgeTopMost`，默认置顶）。

**为什么**：浮窗位置、大小因人而异，置顶与否按习惯选择；拖动/缩放与位置尺寸持久化，下次启动沿用上次结果。

**怎么验证**：设置界面切换常驻、置顶；拖动浮窗后重启位置保留；右下角拖大拖小后重启尺寸保留；ini 新增 `BadgeTopMost` / `BadgeW` / `BadgeH` / `BadgeX` / `BadgeY`。

**限制**：拖动/缩放写 ini 失败时本次仍生效，下次回到上次保存值；多显示器场景未做额外边界裁剪。

## v1.2.2 调整：快捷方式位置可选（桌面/开始菜单）+ 以后不再提示勾选框

**改了什么**：

- 首次启动对话框可勾选快捷方式位置：**桌面**、**开始菜单**（可同时多选，默认勾选桌面）；开始菜单快捷方式放到当前用户「开始菜单\程序」目录，出现在开始菜单所有程序列表；两个都勾选则两处都生成。

- **托盘通知区图标可开关**：右键菜单「显示托盘图标」或设置界面「显示托盘图标」勾选框控制右下角通知区图标是否显示；取消勾选后图标隐藏，程序仍在后台运行。隐藏后可通过全局设置快捷键（默认 `CTRL+ALT+SHIFT+S`）、命令行 `--settings` 打开设置界面重新勾选，或手动把 ini 里 `ShowTrayIcon` 改回 `1`。

**为什么**：v1.2.1 只能放桌面；本版允许进开始菜单，并提供关闭首次弹窗的选项。

## v1.1.8 修复与调整（不改变默认行为）

本版只修问题、加固健壮性，三条硬保证和默认配置不变：

- **「重新载入 AutoIME.ini」现在全部配置项即时生效**：旧版重载时漏掉了严格锁定、放宽形状判定、PS 工具规则、PS 进程列表、四个快捷键、是否允许切布局等项，手改 ini 后必须重启才生效；现已补齐，重载即生效。
- **关闭开机自启会同时清理「启动」文件夹里的 vbs 残留**：旧版只删注册表启动项，若启动文件夹里还留着 `AutoIME.vbs`，开机仍会被拉起；现在关闭时两处一起清。
- **热键失败重试不再叠加定时器**：旧版每次保存/重载都会新建一个重试定时器且旧的不停；现统一复用同一个，全部注册成功后自动停止。

- **离开软件恢复中文前校验窗口句柄真实存活**，不再对已销毁的窗口发消息。

## 常见问题

**Q：输入法切不回来 / 一直英文？**
A：把鼠标移回输入框即可。如果 PS 是以**管理员身份**运行的，本程序也必须以管理员身份运行（托盘右键 →「以管理员身份重新启动」），否则 Windows 会阻止它控制 PS 的输入法。

**Q：为什么不用"切英文键盘"的办法？**
A：也可以，配置里 `Method=layout` 就是。但那样语言栏会跳、搜狗会重新加载，观感差，而且不是你要的 IMBlocker 那种方式。

**Q：会影响我按 Shift 切中英吗？**
A：在**输入框里**你随时可以按 Shift 自己切中/英，**本次输入期间程序不会再改回**（v1.0.7）。
 只有离开这个输入框、去了别的地方，才会重新按规则自动控制（比如回到画布就锁英文）。

**Q：数字框里为什么强制英文？**
A：中文输入法开着的时候，数字键会被拿去选候选字，"输入 50 变成候选字"就是这个问题。所以 `NumClasses` 里的控件一律英文。

**Q：界面是 Qt（Maya、钉钉等）能认出来吗？**
A：能。Qt 的文本框用的是系统标准 I 型光标，直接命中 `StdIBeam` 判据。

**Q：性能开销？**
A：每 40ms 读一次输入法开/关状态，只在 PS/Max/Maya 前台时才做，CPU 占用可忽略。

**Q：工具好像完全没反应，日志里除了"启动"什么都没有？**

A：把配置里 `LogLevel=1` 改成 `LogLevel=2`，重启程序，日志就会每 2 秒记录引擎看到的一切：

```
[调试] Photoshop.exe class='Photoshop' 目标=True 输入框=False(-) caret=False 标准I=False 形状I=False imeWnd=0x11321BE open=1 hkl=0x08040804
```

对照着看就知道卡在哪一步：

| 日志现象 | 含义 | 处理 |
|---|---|---|
| `目标=False` | 没认出这个程序 | 检查 `[Apps]` 里有没有这个进程名 |
| 程序名为空 | 进程名被安全软件拦截 | 本机已遇到过并修好（改用底层接口取进程名） |
| `没有可用的输入法窗口` | 该程序没有 IMM32 输入上下文 | 配置里改 `Method=layout` |
| `输入框=True` 但一直不开 | 判据选择问题 | 诊断面板看「依据」，试着关掉某个判据 |
| `open=0` 但还是能打中文 | 输入法没真正关掉 | 把日志发我 |

**Q：托盘菜单里「开机自动启动」勾了，重启电脑却没生效？**

A：v1.1.1 起会**写完后读回校验**，失败会弹窗（以前是静默失败，界面照样显示已勾选）。

程序会依次尝试：**直接写注册表 Run 键** → **调 reg.exe 代写** → **让 cmd.exe 复制启动器**。

如果全被拦住（本机就是这种情况——实测连子进程都被拦），会弹窗并帮你选中这个文件：

> **`启用开机自启.cmd`**

**双击它一次就好**（它由资源管理器启动，属于受信任链路，不受那个限制）。
想取消就双击同目录的 **`关闭开机自启.cmd`**。

> 这两种操作都是"一次性的"，设完之后开机自动运行，无黑窗，不用再管。

**Q：右键「以管理员身份重新启动」没反应 / 报「操作已被用户取消」？**

A：两种可能，v1.1.3 会自动分辨并告诉你：

1. **已经是管理员权限** —— 菜单项会显示为灰色的「已以管理员权限运行」，不需要重启
2. **系统关闭了 UAC**（注册表 `EnableLUA=0`）—— 这时系统没有提权通道，`runas` 必然报"用户取消"。
   而关闭 UAC 时所有程序本来就是完整管理员权限，所以也不需要重启。

（另外 v1.1.1 修过：重启时新进程会被旧进程的单实例锁挡住而自动退出，现在会等旧进程退出再接管。）

**Q：右键「打开配置文件夹」没反应？**

A：程序会先试 `explorer /select`，没检测到窗口就再试直接打开文件夹，总共等约 7 秒。
如果还是没有窗口，会把路径**复制到剪贴板**（复制失败会如实说明）并弹窗，`Win+R` 粘贴即可。

> 注意：如果 AutoIME 是由**别的程序代为启动**的（例如脚本、计划任务、或被调试工具拉起），
> 打开资源管理器这类"启动外部程序"的动作可能被拦；**自己双击 exe 启动时通常正常**。

## 日志与排障（v1.1.7）

### 日志在哪

- 默认：**`AutoIME.log`**，和 `AutoIME.exe` 同一目录（便携）
- 如果那个目录不可写：`%LOCALAPPDATA%\AutoIME\AutoIME.log`
- 超过 512 KB 会**滚动**成 `AutoIME.log.1`（保留上一份，不会直接删掉历史）

### 日志里记了什么

| 内容 | 例子 |
|---|---|
| 启动环境 | `系统: Windows 11 x64 管理员 UAC=关闭`、程序路径、配置路径、显示器 |
| 每次中/英切换 | `-> Chinese (打开输入法 ← PS文字工具:typeCreateOrEditTool \| Photoshop)` |
| 快捷键 | 注册、注册失败、**热键恢复** |
| 开机自启 | 尝试了哪条路、成功/失败、当前状态 |
| PS 工具助手 | 启动、异常 |
| 你的手动操作 | 在输入框里按 Shift 切中英会被记录 |

时间戳带日期（`11-12 16:26:45.966`），跨天也不会混。

### 一键导出诊断报告

**托盘右键 →「导出诊断报告…」**（诊断面板里也有同名按钮）

会生成 `AutoIME.诊断报告.txt`，包含：

1. 版本、系统、管理员/UAC、显示器
2. 完整配置（`AutoIME.ini` 全文）
3. PS 工具状态（规则开关、可用性、上次工具、忙状态、状态文件路径）
4. 相关进程（Photoshop / 3dsmax / maya / cscript / wscript 的 PID）
5. **最近 300 行日志**（含滚动的上一份）

路径会自动复制到剪贴板，直接发给我即可定位问题。

> 也可以用命令行：`AutoIME.exe --diag-export`

**Q：出问题了看哪里？**
A：同目录的 `AutoIME.log`（记录每次切换和原因），以及诊断面板。
