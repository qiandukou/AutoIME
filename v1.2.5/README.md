# AutoIME v1.2.5 — 输入法自动开关

**给 Adobe / Autodesk 创意软件用的：要用快捷键时自动关掉输入法，鼠标点到输入框时自动开回来。**

不切换输入法、不切换键盘布局、语言栏不跳，你用的还是原来那个搜狗 / 微软拼音。

---

## 快速上手（30 秒）

1. 打开 `releases\v1.2.5\` 文件夹
2. 双击 **`AutoIME.exe`**（右下角出现「英」字样小圆图标即已运行）
3. 打开 Adobe / Autodesk 软件正常用

想改设置：**双击托盘图标**（v1.0.2 新增的设置主界面）。
想开机自动启动：右键托盘图标 → 勾选「开机自动启动」。

想退出：右键托盘图标 → 退出。

---

## 换电脑怎么用

把 **`AutoIME_v1.2.5.zip`**（或者 `releases\v1.2.5\` 整个文件夹）拷到新电脑的任意**可写**目录（比如 `D:\Tools\AutoIME`），
双击 `AutoIME.exe` 就行。第一次运行会自动生成 `AutoIME.ini`。

要求：Windows 10 / 11（自带 .NET Framework 4.x），不需要安装任何运行库。

如果放在 `C:\Program Files` 这种不可写目录，程序会自动把配置改存到 `%LOCALAPPDATA%\AutoIME`。

## 它是怎么工作的

```
光标在输入框 / 正在打字  →  放行输入法（中文）
其它所有时候            →  锁定输入法（按键直达软件，快捷键正常）
```

三条硬保证：

1. **绝不切换键盘布局**：语言栏不跳、输入法不重载
2. **严格锁定**：不在输入框时，按 Shift 把输入法撬开也会被立刻关回去
3. **只在输入框放行**

用的接口是 `ImmGetDefaultIMEWnd` + `WM_IME_CONTROL` + `IMC_SETOPENSTATUS`
（原理和「我的世界」的 IMBlocker 插件一致：只是外部程序只能开关输入法，不能像插件那样把输入法从窗口上摘掉）。

## PS 画布上打字要先教一次

PS 画布的文字光标是 PS 自己画的，程序认不出形状。首次使用：

1. 按 `T` 选文字工具 → 鼠标移到画布上，等出现 I 型文字光标
2. 按 **`Ctrl + Alt + Shift + L`**
3. 浮标提示「已学习 Photoshop」→ 完成

## 要加新功能 / 让别的 AI 改

**先读 [`版本管理规则.md`](版本管理规则.md)，核心是：已发布的版本目录只读，绝不修改。**

```powershell
cd <这个目录>
.\新版本.ps1 1.1.9      # 复制出 v1.1.9，自动改版本号、编译、写入更新日志占位
# 只在 releases\v1.1.9\AutoIME.cs 里改功能
.\发布检查.ps1 1.1.9    # 发布前必须跑，全部通过才算完成
```

**每个新版本必须同时更新三样，缺一不可：**

| 要更新的 | 是什么 |
|---|---|
| `releases\vX.Y.Z\AutoIME.cs` | 代码 |
| `releases\vX.Y.Z\使用说明.md` | **软件说明**（新功能 / 新配置项 / 新限制都要写） |
| `更新日志\CHANGELOG.md` | **更新日志**（改了什么 / 为什么 / 怎么验证的） |

`发布检查.ps1` 会逐项核对，还会检查**旧版本目录有没有被偷偷改动**；缺任何一项都会拦下来（退出码 1）。

详细流程、给 AI 的开场提示、自检清单都在 `版本管理规则.md` 里。

## 常见问题

**快捷键没反应 / 输入法一直是开的？**
看 `AutoIME.log`；把 `AutoIME.ini` 里 `LogLevel` 改成 `2` 重启，日志会每 2 秒记录引擎看到的一切。

**PS 以管理员身份运行？**
本程序也要以管理员身份运行（托盘右键 →「以管理员身份重新启动」）。

**会不会影响我按 Shift 切中英？**
在输入框里会尊重你的手动切换（暂停 4 秒）；不在输入框时会被锁回关闭状态——这是「严格锁定」，就是为了保证快捷键可用。

更多配置项和排错见 [`releases\v1.2.5\使用说明.md`](releases/v1.2.5/使用说明.md)。
