# AutoIME — 创意软件输入法自动开关

给 Adobe / Autodesk 创意软件用的小工具：**要用快捷键时自动关掉输入法，鼠标点到输入框时自动开回来。** 不切换输入法、不切换键盘布局、语言栏不跳，你用的还是原来那个搜狗 / 微软拼音。

- 版本：v1.2.5

## 它解决什么问题

中文输入法开着时，Photoshop、3ds Max、Maya 里按 `V`、`M`、`W` 这类字母快捷键，会被输入法当成拼音吃掉。

AutoIME 只做一件事——**锁定 / 放行输入法**：

| 场景 | 输入法状态 | 效果 |
|---|---|---|
| 光标在输入框 / 正在打字 | 放行（中文） | 能正常打中文 |
| 其它所有时候（用快捷键） | 锁定（关闭） | 按键直达软件，快捷键正常 |

三条硬保证：

1. **绝不切换键盘布局**：语言栏不跳、输入法不重载，键盘布局始终是原来那个；
2. **严格锁定**：不在输入框时，就算手动按 Shift 把输入法撬开，也会在几十毫秒内关回去；
3. **只在输入框放行**：光标进入输入框立刻开中文，离开就锁上。

底层接口：`ImmGetDefaultIMEWnd` + `WM_IME_CONTROL` + `IMC_SETOPENSTATUS`。

## 快速上手

1. 进入仓库目录 [`v1.2.5/`](v1.2.5/)；
2. 双击 **`AutoIME.exe`**，右下角托盘出现「英」字样小圆图标即已运行；
3. 打开 Photoshop / 3ds Max / Maya 正常使用。

- 改设置：双击托盘图标，或右键托盘图标 → 设置；
- 开机自启：右键托盘图标 → 勾选「开机自动启动」；
- 退出：右键托盘图标 → 退出。

> 首次运行会在 exe 同目录生成 `AutoIME.ini` 配置；若目录不可写（如 `C:\Program Files`），配置自动存到 `%LOCALAPPDATA%\AutoIME`。

## Photoshop 画布打字：先学习一次

PS 画布的文字光标是 PS 自己绘制的，程序认不出形状，首次使用需教一次：

1. 按 `T` 选文字工具，鼠标移到画布上出现 I 型文字光标；
2. 按 `Ctrl + Alt + Shift + L`；
3. 浮标提示「已学习 Photoshop」即完成。

> 该识别由同目录的 `AutoIME.PsTool.vbs` 助手配合完成，需和 exe 放在同一目录。

## 常见问题

**快捷键没反应、输入法一直是开的？**
查看 `AutoIME.log`；把 `AutoIME.ini` 里 `LogLevel` 改成 `2` 重启，日志会每 2 秒记录引擎看到的状态。

**PS 以管理员身份运行？**
本程序也要以管理员身份运行（托盘右键 →「以管理员身份重新启动」）。

**会不会影响手动按 Shift 切中英？**
在输入框内会尊重手动切换（暂停约 4 秒）；不在输入框时会被锁回关闭，这是「严格锁定」，用于保证快捷键可用。
